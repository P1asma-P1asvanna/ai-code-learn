# AI Code Learn

เว็บเรียนเขียนโค้ดฟรี: อ่านบทเรียน → เขียนโค้ดใน Playground แล้วรันได้เลย → เปิด **AI ช่วยตรวจโค้ด** เมื่ออยากได้คำใบ้ (ปิดไว้ได้ถ้าอยากลองคิดเอง)

ทำตามคู่มือนี้ได้ **ผ่าน browser อย่างเดียว ไม่ต้องติดตั้งโปรแกรมอะไรในเครื่อง** (ไม่ต้องใช้ Git, Python, Node)

| ส่วน | ใช้อะไร | ค่าใช้จ่าย |
|---|---|---|
| หน้าเว็บ | Next.js บน Vercel | ฟรี |
| หลังบ้าน (API) | FastAPI บน Render | ฟรี (หลับเมื่อไม่มีคนใช้ 15 นาที) |
| ฐานข้อมูล | PostgreSQL บน Neon | ฟรี |
| ล็อกอิน | GitHub OAuth (Auth.js) | ฟรี |
| รันโค้ดของผู้เรียน | ในเบราว์เซอร์ของผู้เรียนเอง (Python = Pyodide, JavaScript = Web Worker) | ฟรี ไม่มีเซิร์ฟเวอร์รันโค้ด |
| AI ตรวจโค้ด (เสริม) | Gemini ผ่าน Google AI Studio (เปลี่ยนเป็นเจ้าอื่นได้) | ฟรีตามโควต้าของ Google |

---

## สิ่งที่ทำได้แล้วในเวอร์ชันนี้

- ✅ Playground: เขียนโค้ด Python / JavaScript (Monaco editor เหมือน VS Code) กด ▶ รัน หรือ Ctrl/⌘ + Enter, หยุดเองถ้าโค้ดวนไม่รู้จบเกิน 10 วินาที
- ✅ **AI ช่วยตรวจโค้ด** (เสริม): กด "ตรวจโค้ดตอนนี้" หรือเปิดสวิตช์ "ตรวจให้อัตโนมัติขณะเขียน" (หยุดพิมพ์ 2-3 วินาทีแล้ว AI ถึงตรวจ) จุดที่ AI เจอจะขีดเส้นใต้ในโค้ดและกดข้ามไปบรรทัดนั้นได้ AI ให้คำใบ้ ไม่เฉลยทั้งก้อน ถ้ารันแล้วเกิด error จะอธิบาย error นั้นให้ด้วย
  - **ค่าเริ่มต้นคือปิด** และเว็บทำงานปกติแม้ไม่ได้ตั้งค่า AI เลย
  - มีโควต้าต่อคน (60 ครั้ง/วัน, 10 ครั้ง/นาที) และโควต้ารวมทั้งระบบ เพื่อไม่ให้โควต้าฟรีหมดเร็ว
- ✅ **บทเรียน**: Python และ JavaScript ภาษาละ 5 บท (พิมพ์ผลลัพธ์, ตัวแปร, เงื่อนไข, loop, ฟังก์ชัน) อ่านได้โดยไม่ต้องล็อกอิน ตัวอย่างโค้ดกด “นำไปลองในตัวแก้ไข” แล้วรันได้ทันที
- ✅ **แบบฝึกหัด + คะแนน**: ปรนัยและเขียนโค้ด (ระบบรันโค้ดคุณในเบราว์เซอร์ด้วยค่าที่ต่างกันหลายรอบแล้วเทียบผลลัพธ์) ได้คะแนนครั้งแรกที่ตอบถูกเท่านั้น ตอบซ้ำฝึกได้ไม่บวกซ้ำ ทำครบทุกข้อบทนั้นถือว่าเรียนจบอัตโนมัติ (ต้องล็อกอินเพื่อเก็บคะแนน)
- ✅ **Dashboard** (`/dashboard`): คะแนนรวม, บทที่เรียนจบ, แบบฝึกหัดที่ผ่าน, ความคืบหน้าแยกตามคอร์ส, บทเรียนล่าสุด และปุ่ม “เรียนต่อ” ไปยังบทถัดไป
- ✅ ล็อกอินด้วย GitHub
- ⏳ ยังไม่ทำ (เฟสถัดไป): AI Tutor แบบแชต

## ขั้นตอน Deploy (ประมาณ 45-60 นาที)

### เตรียมก่อนเริ่ม

เปิด Notepad (หรือแอปจดอะไรก็ได้) ไว้ข้าง ๆ แล้วจดค่าที่ได้ในแต่ละขั้นไว้ จะใช้ในขั้นหลัง ๆ

**คิดชื่อเว็บของคุณก่อน** เช่น `ai-code-learn-somchai` (ภาษาอังกฤษพิมพ์เล็ก ตัวเลข และ `-` เท่านั้น) แล้วจดไว้ (ในคู่มือนี้เรียกว่า **ชื่อโปรเจกต์**) เว็บของคุณจะอยู่ที่

```
https://ชื่อโปรเจกต์.vercel.app
```

ขั้นหลังจะใช้ URL นี้ในหลายที่ จึงต้องตัดสินใจก่อน

**ทำรหัสลับ 2 ตัว** (ยาว ๆ มั่ว ๆ ไม่ต้องจำ):

1. เปิดแท็บใหม่ใน Chrome ไปหน้าอะไรก็ได้ กด `F12` แล้วเลือกแท็บ **Console**
2. พิมพ์ `allow pasting` กด Enter (Chrome ขอแบบนี้ก่อนวางโค้ด)
3. วางบรรทัดนี้แล้วกด Enter:
   ```js
   crypto.randomUUID().replaceAll("-","") + crypto.randomUUID().replaceAll("-","")
   ```
4. ได้ตัวอักษรยาว 64 ตัว คัดลอกไปจดไว้ชื่อ **JWT_SECRET**
5. กด Enter ซ้ำอีกรอบ ได้อีกชุด จดไว้ชื่อ **NEXTAUTH_SECRET**

> อย่าเอารหัสลับสองตัวนี้ไปโพสต์ที่ไหน และอย่าใส่ใน GitHub

### ขั้นที่ 1 — อัปโหลดโค้ดขึ้น GitHub

1. คลิกขวาที่ `ai-code-learn.zip` → **Extract All** → Extract ไฟล์จะไปอยู่ในโฟลเดอร์ใหม่ชื่อ `ai-code-learn` (แนะนำให้ย้ายโฟลเดอร์นี้ไปไว้ที่ Documents หรือ Desktop ก่อน อย่าให้อยู่ในโฟลเดอร์ระบบ เช่น AppData หรือ Start Menu)
2. เปิดโฟลเดอร์นั้น **ต้องเห็น `backend`, `frontend`, `README.md`, `render.yaml` ได้ทันที** ถ้าเห็นโฟลเดอร์ชื่อ `ai-code-learn` ซ้อนอยู่ข้างในอีกชั้น ให้เปิดเข้าไปอีกชั้นหนึ่งจนเห็นไฟล์เหล่านั้น
3. เปิดหน้า repo `ai-code-learn` ของคุณบน github.com แล้วกดลิงก์ **uploading an existing file** (อยู่ในกรอบ Quick setup)
4. กด `Ctrl + A` ในโฟลเดอร์ที่เปิดอยู่เพื่อเลือกทุกอย่าง แล้ว **ลากทั้งหมดลงหน้าเว็บ** (ไม่ใช่ลากตัวโฟลเดอร์แม่ทั้งก้อน)
5. รอจนไฟล์ขึ้นครบ เลื่อนลงล่างสุด กด **Commit changes**
6. เช็คว่าหน้า repo เห็นโฟลเดอร์ `backend`, `frontend` และไฟล์ `render.yaml` แล้ว
7. (ถ้า `.github` ติดมาด้วย) ไปที่แท็บ **Actions** รอ 2-3 นาทีให้ระบบตรวจโค้ดอัตโนมัติ ถ้าเห็นเครื่องหมายถูกสีเขียวแปลว่าโค้ดผ่านการตรวจ ถ้าเป็นกากบาทสีแดง ให้คลิกเข้าไปดูข้อความ error แล้วส่งให้ Claude ช่วยดู **ก่อนไปขั้นถัดไป**

> ถ้าโฟลเดอร์ที่ขึ้นต้นด้วยจุด (`.github`) ไม่ติดมา ไม่เป็นไร เว็บยังใช้ได้ปกติ (มันคือระบบตรวจโค้ดอัตโนมัติ ใส่ทีหลังได้)

### ขั้นที่ 2 — สร้างฐานข้อมูล (Neon)

1. ไป **neon.com** → Sign up → เลือกสมัครด้วย GitHub
2. กด **Create project** ตั้งชื่ออะไรก็ได้ ส่วน Region เลือก **Singapore**
3. พอสร้างเสร็จ กดปุ่ม **Connect** แล้วกด **Copy snippet** หรือคัดลอก connection string ที่ขึ้นต้นด้วย `postgresql://...`
4. จดไว้ชื่อ **DATABASE_URL** (ไม่ต้องแก้อะไรในสตริงนั้น) — เช็คว่าในสตริงมีรหัสผ่านจริง ไม่ใช่เครื่องหมาย `*****` ถ้าเป็นจุด ๆ ให้ติ๊ก Show password ก่อนคัดลอก

### ขั้นที่ 3 — สร้างปุ่มล็อกอินด้วย GitHub

1. ไปที่ **github.com/settings/developers** → **OAuth Apps** → **New OAuth App**
2. กรอก
   - Application name: ชื่ออะไรก็ได้
   - Homepage URL: `https://ชื่อโปรเจกต์.vercel.app`
   - Authorization callback URL: `https://ชื่อโปรเจกต์.vercel.app/api/auth/callback/github`
3. กด **Register application**
4. จด **Client ID** ไว้ชื่อ **GITHUB_ID**
5. กด **Generate a new client secret** แล้วจดค่าที่ขึ้นมาไว้ชื่อ **GITHUB_SECRET** (ค่านี้จะเห็นครั้งเดียว)

### ขั้นที่ 4 — ติดตั้งหลังบ้าน (Render)

1. ไป **render.com** → Sign up → เลือกสมัครด้วย GitHub
2. กด **New +** → **Blueprint** → เลือก repo `ai-code-learn` (ถ้าไม่เห็น repo ให้กด Configure account แล้วอนุญาตให้ Render เข้าถึง repo นี้)
3. Render จะอ่านไฟล์ `render.yaml` แล้วขึ้นช่องให้กรอก 3 ช่อง

   | ช่อง | ใส่อะไร |
   |---|---|
   | DATABASE_URL | ค่าจากขั้นที่ 2 |
   | JWT_SECRET | ค่า JWT_SECRET ที่ทำไว้ตอนเตรียม |
   | CORS_ORIGINS | `https://ชื่อโปรเจกต์.vercel.app` (ห้ามมี `/` ปิดท้าย) |

4. กด **Apply** แล้วรอ 5-10 นาทีจนสถานะเป็น **Live** (สีเขียว)
5. คัดลอก URL ของ service (อยู่ใต้ชื่อ แบบ `https://ai-code-learn-api.onrender.com`) จดไว้ชื่อ **API_URL**
6. ลองเปิด `API_URL/health` ใน browser ถ้าเห็น `{"status":"ok"}` แปลว่าหลังบ้านใช้ได้แล้ว

> ครั้งแรกที่เปิดลิงก์ ถ้า Render เพิ่งตื่น อาจรอประมาณ 1 นาที

### ขั้นที่ 5 — ติดตั้งหน้าเว็บ (Vercel)

1. ไป **vercel.com** → Sign up → เลือกสมัครด้วย GitHub
2. กด **Add New… → Project** → กด **Import** ที่ repo `ai-code-learn`
3. ช่อง **Project Name** ใส่ชื่อโปรเจกต์ที่คิดไว้ (ต้องตรงกับที่ใช้ในขั้นที่ 3 และ 4)
4. ช่อง **Root Directory** กด **Edit** แล้วเลือกโฟลเดอร์ **`frontend`** ⚠️ ขั้นนี้สำคัญที่สุด ถ้าลืม build จะพัง
5. เปิดหัวข้อ **Environment Variables** แล้วเพิ่ม 6 ค่า (ใส่ชื่อ → ใส่ค่า → Add)

   | ชื่อ | ค่า |
   |---|---|
   | NEXT_PUBLIC_API_URL | API_URL จากขั้นที่ 4 (ไม่มี `/` ปิดท้าย) |
   | NEXTAUTH_URL | `https://ชื่อโปรเจกต์.vercel.app` |
   | NEXTAUTH_SECRET | ค่า NEXTAUTH_SECRET ที่ทำไว้ตอนเตรียม |
   | BACKEND_JWT_SECRET | **ค่าเดียวกับ JWT_SECRET** (ที่ใส่ไว้ใน Render) |
   | GITHUB_ID | จากขั้นที่ 3 |
   | GITHUB_SECRET | จากขั้นที่ 3 |

6. กด **Deploy** รอ 1-3 นาที

> ถ้า Vercel แจ้งว่าชื่อโปรเจกต์ถูกใช้แล้ว หรือ URL ที่ได้ไม่ตรงกับที่ตั้งใจ ให้กลับไปแก้ 3 ที่ให้ตรงกับ URL จริง: `NEXTAUTH_URL` (Vercel → Settings → Environment Variables แล้ว Redeploy), `CORS_ORIGINS` (Render → Environment) และ Homepage/callback URL ของ OAuth App (ขั้นที่ 3)

### ขั้นที่ 6 — ทดสอบ

เปิด `https://ชื่อโปรเจกต์.vercel.app` แล้วไล่เช็คตามนี้

- [ ] หน้าแรกเห็นรายชื่อภาษา Python และ JavaScript (รอแป๊บถ้า Render เพิ่งตื่น)
- [ ] เข้า **Playground** กด ▶ รัน ได้ผลลัพธ์ (Python ครั้งแรกโหลดนาน 10-30 วินาที เพราะต้องโหลดตัวรัน Python ~10 MB หลังจากนั้นเร็ว)
- [ ] กด **เข้าสู่ระบบด้วย GitHub** แล้วล็อกอินสำเร็จ
- [ ] (ถ้าทำขั้นที่ 7 แล้ว) หลังล็อกอิน แผง "AI ช่วยตรวจโค้ด" มีสวิตช์ให้เปิด กด "ตรวจโค้ดตอนนี้" แล้วได้คำแนะนำ

### ขั้นที่ 7 — เปิดระบบ AI ตรวจโค้ด (ไม่บังคับ)

เว็บใช้งานได้เต็มที่แม้ไม่ทำขั้นนี้ (แผง AI จะขึ้นว่า "ผู้ดูแลยังไม่ได้เปิดใช้") ทำเมื่อพร้อมได้เลย

1. ไป **aistudio.google.com/apikey** ล็อกอินด้วยบัญชี Google → กด **Create API key** → คัดลอกคีย์
2. ไปที่ Render → เลือก service `ai-code-learn-api` → แท็บ **Environment** → **Add Environment Variable**
3. ชื่อ `AI_API_KEY` ค่า = คีย์ที่คัดลอก → **Save Changes** (Render จะ restart เอง ใช้เวลาประมาณ 1-2 นาที)
4. เปิดหน้า Playground แล้วรีเฟรช ล็อกอิน จะเห็นสวิตช์ "ตรวจให้อัตโนมัติขณะเขียน" และปุ่ม "ตรวจโค้ดตอนนี้"

## ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| Vercel build พัง ขึ้นว่าหา package.json ไม่เจอ | ลืมตั้ง Root Directory เป็น `frontend` (ขั้นที่ 5 ข้อ 4) แก้ที่ Settings → General → Root Directory แล้ว Redeploy |
| Render deploy ไม่ผ่าน อ่านใน Logs เจอ error เรื่อง `JWT_SECRET` | รหัสลับสั้นกว่า 32 ตัวอักษร ให้ทำใหม่ตามหัวข้อ "เตรียมก่อนเริ่ม" |
| Render deploy ไม่ผ่าน เจอ error เกี่ยวกับ database | `DATABASE_URL` ผิดหรือขาดบางส่วน คัดลอกใหม่จาก Neon ให้ครบทั้งบรรทัด |
| หน้าแรกขึ้นว่า "เชื่อมต่อเซิร์ฟเวอร์ไม่ได้" | Render หลับอยู่ รอ 1 นาทีแล้วรีเฟรช หรือ `NEXT_PUBLIC_API_URL` ผิด (แก้แล้วต้อง Redeploy เพราะค่านี้ถูกฝังตอน build) |
| กดล็อกอินแล้วขึ้น error redirect_uri / callback | callback URL ใน OAuth App ไม่ตรงกับ URL จริง (ขั้นที่ 3) |
| ล็อกอินผ่านแต่ AI ขึ้นว่า "เซสชันหมดอายุ" / 401 | `BACKEND_JWT_SECRET` (Vercel) กับ `JWT_SECRET` (Render) ไม่ตรงกัน แก้ให้ตรงกันแล้ว Redeploy ทั้งสองฝั่ง |
| เรียก API ไม่ได้ ใน Console ขึ้นคำว่า CORS | `CORS_ORIGINS` บน Render ไม่ตรงกับ URL ของเว็บ (ต้องมี `https://` และไม่มี `/` ปิดท้าย) |
| AI ขึ้น "ติดต่อ AI ไม่สำเร็จ" | เปิด Render → Logs แล้วดูบรรทัด `AI provider error:` มันบอกสาเหตุ เช่น คีย์ผิด หรือชื่อรุ่นถูกปลดระวาง (ดูหัวข้อถัดไป) |
| รัน Python แล้วค้างที่ "กำลังโหลด Python" นาน | อินเทอร์เน็ตช้าหรือโหลดจาก CDN ไม่สำเร็จ ลองรีเฟรช ถ้ายังไม่ได้ให้ดูหมายเหตุเรื่อง Pyodide ด้านล่าง |

## ตั้งค่า AI ตรวจโค้ด

ตั้งผ่านตัวแปรในหน้า Render → Environment (แก้แล้วระบบ restart เอง) ตัวแปรที่ไม่ได้ตั้งจะใช้ค่าเริ่มต้นในตาราง

| ตัวแปร | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `AI_API_KEY` | คีย์ของผู้ให้บริการ AI (ว่าง = ปิดระบบ AI) | ว่าง |
| `AI_BASE_URL` | ที่อยู่ API ของผู้ให้บริการ | Gemini |
| `AI_MODEL` | ชื่อรุ่น ใส่ได้หลายชื่อคั่นด้วย `,` ถ้าชื่อแรกใช้ไม่ได้ (404) จะลองชื่อถัดไปเอง | `gemini-flash-lite-latest,gemini-flash-latest,gemini-3.1-flash-lite` |
| `AI_DAILY_REQUEST_LIMIT` | จำนวนครั้ง/วัน/คน | 60 |
| `AI_PER_MINUTE_LIMIT` | จำนวนครั้ง/นาที/คน | 10 |
| `AI_GLOBAL_DAILY_LIMIT` | จำนวนครั้ง/วัน ทั้งระบบ | 800 |
| `AI_ENABLED` | ใส่ `false` เพื่อปิด AI ชั่วคราวโดยไม่ต้องลบคีย์ | true |

**ใช้ AI เจ้าอื่น**: ระบบคุยแบบ "OpenAI chat completions" ซึ่งผู้ให้บริการส่วนใหญ่รองรับ แค่เปลี่ยน 3 ตัว `AI_BASE_URL`, `AI_API_KEY`, `AI_MODEL`

- Groq: `https://api.groq.com/openai/v1`
- OpenRouter: `https://openrouter.ai/api/v1`
- ชื่อรุ่นให้ดูจากหน้ารายชื่อรุ่นของผู้ให้บริการนั้น (ชื่อเปลี่ยนบ่อย)

**โควต้าฟรีของ Google**: Google ไม่ได้ประกาศตัวเลขโควต้าคงที่ ให้ดูของจริงที่ aistudio.google.com/rate-limit ถ้าโควต้าจริงต่ำกว่าที่ตั้งไว้ในระบบ ให้ลด `AI_DAILY_REQUEST_LIMIT` / `AI_GLOBAL_DAILY_LIMIT`

**เรื่องข้อมูล**: เมื่อใช้ AI ตรวจ โค้ดและข้อความ error ที่แสดงอยู่จะถูกส่งไปยังผู้ให้บริการ AI ภายนอก (หน้าเว็บมีข้อความเตือนผู้เรียนแล้ว) แพ็กเกจฟรีของผู้ให้บริการบางเจ้าอาจนำข้อมูลไปปรับปรุงผลิตภัณฑ์ ควรอ่านเงื่อนไขของเจ้าที่เลือกก่อนเปิดให้คนอื่นใช้

## ข้อจำกัดและข้อควรระวัง (พูดตรง ๆ)

- **Render ฟรีหลับ**: ไม่มีคนใช้ 15 นาที มันจะหลับ คำขอแรกหลังจากนั้นช้าราว 1 นาที เป็นเรื่องปกติของแพ็กเกจฟรี หน้า Playground จะปลุกมันให้อัตโนมัติตอนเปิด
- **โค้ดรันในเบราว์เซอร์ของผู้เรียน**: ฟรีและปลอดภัยต่อเซิร์ฟเวอร์ แต่ผลรันตรวจโกงไม่ได้ ใช้เป็นแบบฝึกหัดได้ แต่อย่าใช้ออกใบรับรองหรือจัดอันดับแข่งขัน (ถ้าอยากทำ ต้องเพิ่มตัวรันฝั่งเซิร์ฟเวอร์ภายหลัง)
- **โค้ด JavaScript ของผู้เรียนถูกล็อกไม่ให้เรียกอินเทอร์เน็ต** (ทดสอบกับ Chromium จริงแล้ว) แต่โค้ด **Python ยังไม่ได้ล็อก** เพราะ Pyodide ต้องโหลดไฟล์จาก CDN ซึ่งยังทดสอบกับเบราว์เซอร์จริงไม่ได้ จึงอย่าเอาโค้ดที่ไม่รู้ที่มาจากคนอื่นมารันในเว็บที่ล็อกอินอยู่
- **`input()` ใน Python ยังใช้ไม่ได้** (จะเกิด EOFError)
- **Pyodide โหลดจาก CDN (jsdelivr)**: ตัวรัน Python ผูกกับเวอร์ชัน `0.27.7` ในไฟล์ `frontend/public/workers/python-worker.js` ถ้า Python ไม่ยอมโหลดเลยทั้งที่เน็ตปกติ ให้ลองเปลี่ยนเลขเวอร์ชันเป็นรุ่นที่ปรากฏในเว็บ pyodide.org
- **ตารางในฐานข้อมูลสร้างอัตโนมัติ** ตอนเริ่มระบบ (เหมาะกับ MVP) ถ้าวันหนึ่งต้องเปลี่ยนโครงสร้างตารางที่มีข้อมูลจริงแล้ว ต้องเพิ่มระบบ migration (Alembic) ก่อน

## แก้โค้ดต่อโดยไม่ต้องติดตั้งอะไร

เปิดหน้า repo บน github.com แล้วกดปุ่มคีย์บอร์ด **`.`** (จุด) จะได้ VS Code เต็มจอบน browser (github.dev) แก้ไฟล์ → แท็บ Source Control → ใส่ข้อความ → Commit & Push พอ push เสร็จ Vercel กับ Render จะ deploy ให้เองอัตโนมัติ

## เพิ่ม/แก้บทเรียน

เนื้อหาทั้งหมดอยู่ในไฟล์เดียว `backend/app/services/course_content.py` (ข้อความบทเรียนเป็น Markdown) แก้ไฟล์นี้แล้ว push → Render ซิงก์เข้าฐานข้อมูลให้เองตอนเริ่มระบบ (ต้องมี `AUTO_SEED=true` ซึ่งตั้งไว้ใน `render.yaml` แล้ว) ทำซ้ำกี่ครั้งก็ได้ ไม่ลบคะแนนของผู้เรียน

- บทเรียน/คอร์สจับคู่ด้วย `slug` — เปลี่ยน slug = สร้างบทใหม่ (ความคืบหน้าของบทเดิมไม่ย้ายตาม)
- แบบฝึกหัดจับคู่ด้วย **ลำดับในบทเรียน** — อย่าสลับลำดับข้อ ให้เพิ่มข้อใหม่ต่อท้าย
